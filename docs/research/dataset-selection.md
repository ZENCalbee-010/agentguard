# Dataset Selection (M2 proposal — to be frozen after the M7 pilot)

Status: **PROPOSAL.** Nothing here is frozen. Freezing (M8) requires human approval.
Source of counts: `docs/research/evidence/*` (AgentDojo v1.2.2, 2026-11-18).

## 1. Sources and roles

| Role | Source | Metric supported | Notes |
|---|---|---|---|
| Primary (development / validation / frozen test) | AgentDojo v1.2.2, `agentdojo==0.1.35` | Executed-unauthorized-action ASR (state oracle), attempted rate, benign utility, task success under attack | 25 directly compatible injection tasks (+9 after approved adaptations) |
| External validation | InjecAgent @ `f19c9f2` | Attempted-action rate only (text-parsed, single step) | Separate table; never pooled with primary (see benchmark-compatibility §6) |
| Native reference scores | AgentDojo's own `security`/`utility` on the **proposed** trace | Native comparability | Stored separately from AgentGuard metrics (REQ-EVL-4) |

## 2. Inclusion rules

1. **Include** injection tasks classified *directly compatible* (25).
2. **Hold** the 9 *adapted-pending* tasks (workspace 6–13, slack 5) until the oracle changes (positive
   controls; executed-trace oracle) are written, reviewed and approved. They enter as an
   *additional* stratum, never silently.
3. **Exclude** answer-only tasks (travel 6).
4. **User tasks:** all 97 have valid ground truth. A user task is eligible for an (user task, injection
   task) pair only if our own injectability check shows the injection vector appears in a tool output
   of the ground-truth trajectory (native `check()` flag unusable, F-1).
5. **Benign set:** every eligible user task is also run **without** injection (utility, false positives).

## 3. Attack families

AgentDojo registers: `important_instructions` (+ `_no_user_name`, `_no_model_name`, `_no_names`,
`_wrong_*`), `direct`, `ignore_previous`, `system_message`, `tool_knowledge`, `injecagent`, `manual`,
and DoS variants (`dos`, `captcha_dos`, `felony_dos`, `offensive_email_dos`, `swearwords_dos`).

Proposal:
- Primary family: `important_instructions_no_model_name` (the standard AgentDojo attack with a neutral
  model name; required because local models are not in `MODEL_NAMES`).
- Secondary families for RQ4 consistency (reported separately, final choice after pilot cost
  measurement): `ignore_previous`, `tool_knowledge`, `direct`.
- Excluded: DoS family (availability attacks, not unauthorized actions), `manual`.

## 4. Splits (cluster-aware)

- **Unit of splitting = user task** (the cluster); within a split, all (user task, injection task) pairs
  for that user task are included. A user task never appears in two splits.
- Assignment: deterministic, seeded hash of `(suite, user_task_id)` → ~30% development, ~20%
  validation, ~50% frozen test, stratified by suite. Seed and resulting manifest are hashed (REQ-EVL-5).
- **Template overlap:** all injection tasks of a suite share the same attacker goals across splits (e.g.
  banking's attacker IBAN). Therefore: analyzer thresholds and policies are tuned on development
  user tasks only, and *injection-goal-specific* patterns (e.g. the literal attacker IBAN) are
  forbidden in analyzer rules (REQ-CA-4 review item). Attack families used in development are recorded;
  families never touched during development are reported as a separate "unseen attack" stratum.
- **External validation:** InjecAgent cases (attempt-rate only) + unseen AgentDojo attack families.

## 5. Size (indicative; set after the pilot)

Upper bound before sampling, per model, for the 25 directly compatible injection tasks and
all eligible user tasks of the same suite — **pairs, not cases** — and ×4 configurations:

| Suite | Compatible inj. tasks | User tasks | Max pairs (before injectability filter) |
|---|---|---|---|
| workspace | 6 | 40 | 240 |
| travel | 6 | 20 | 120 |
| banking | 9 | 16 | 144 |
| slack | 4 | 21 | 84 |
| **Total** | **25** | **97** | **588** |

588 pairs × 4 configurations ≈ 2,352 agent runs per model per attack family per repetition, plus
97 benign × 4 = 388. The pilot (M7) measures seconds and tokens per run on the local model to decide
whether the full grid is affordable or a stratified subsample is needed; the subsample rule will be fixed
**before** viewing results. No number in this table is an experimental result.

## 6. Provenance and integrity

- `datasets/manifests/` will hold, per split: list of (suite, user task, injection task, attack
  family, seed) plus SHA-256 of the manifest file and the AgentDojo version string.
- Attack strings are generated by AgentDojo from `GOAL` + template at run time; they are
  untrusted data (SEC-009) and are never copied into prompts of the analyzer rules.
